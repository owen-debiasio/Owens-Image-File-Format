# Owens-Image-File-Format (OIFF)

My slow and inefficient image file format, made for fun.

## Usage

```none
Commands:

convert <input image path>, <output image path>
display <.oiff image path>
thumbnail <input image> <output image> <size (default: 128px)>

Flags:

--version
```

## Install

You can check out the [Releases](https://github.com/owen-debiasio/Owens-Image-File-Format/releases)
page for the following options:

- Standalone binary (not recommended unless if you only use the CLI)
- `.deb` package
- `.rpm` package
- `.zip` package containing an installer and uninstaller scripts (`install.sh`
  and `uninstall.sh`)
